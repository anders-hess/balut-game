# ADR-026 — Seven-category exact-quota Bellman upper relaxation (Oracle iteration 31)
**Date:** 2026-11-02. **Status:** ACCEPTED RESEARCH UPPER-BOUND COMPONENT, NOT A PROVEN OPTIMAL EARLY-GAME ORACLE, NOT LIVE.
**Binding:** ORACLE_NORTH_STAR.md; exact <=7-turn Bellman, all seven future categories may adapt after every roll, objective = globally optimal expected FINAL Big Points over 28 turns. Previous ADR-023 V28 lower and ADR-025 negative gap remain valid.

## Why this is a substantive mathematical change
Earlier V15/V28 upper relaxations treated Big Point bonuses and final Small Points bonus rather separately, and the V12 Lagrangian relaxation priced category capacity without enforcing all seven actual category quotas. V31 solves a **seven-category quota-constrained stochastic Bellman problem across all 28 turns**, retaining exactly one category per turn, exactly `k_c=4-filled_c` scoring events per category, exact dice reroll dynamics (252 unordered dice histograms, 210 useful holds, two rerolls), and arbitrary future adaptation among still-open categories. To make the 28-turn problem tractable, ONLY the nonlinear terminal Big Point reward structure is replaced by pathwise additive upper majorants.

## Proof of real-arithmetic admissibility
For threshold categories `c in {4s,5s,6s,Choice}` with needed remainder `h_c>0`, a successful +2 bonus is bounded pathwise by `(2/h_c) × sum_future(category-small)`. Already achieved threshold contributes constant +2; permanently unreachable threshold contributes 0. Four-valid Straight/Full House bonus is bounded by `(4/k_straight) × number_future_successful_straights` or `(3/k_house) × number_future_successful_houses` when historical row remains intact and k>0; closed/failed rows are constants. Each successful future Balut contributes exactly +2. Call the sum of these category-additive majorants `r_c(d)` plus already secured rewards `G(s)`.
For every alpha >=0 let `k` be actual remaining quotas and define `beta_s(alpha)=max_{x ∈ [5*k_Choice, SUM_c(k_c*maximumSmall_c)]∩Z}( B(s.totalSmall+x) − alpha*x )` for the genuine terminal Big Point bonus B. Since future Small Points x always lie in that integer range, `B(s.totalSmall+x)≤beta_s(alpha)+alpha*x` **pathwise**. Therefore for any globally adaptive legal future action sequence: `FinalBigPoints≤G(s)+beta_s(alpha)+SUM_future[r_c(d)+alpha*small_c(d)]`.
Compute `W_alpha(k)` by exact finite quota Bellman over all seven categories and reroll actions, with immediate reward `r_c(d)+alpha*small_c(d)` and transitions `k→k−e_c`. The full abstract state space has at most `5^7=78,125` quota states, including zero. This is EXACT for the additive surrogate, upper for original Balut: `V*(s) ≤ G(s)+beta_s(alpha)+W_alpha(k)`. The same `W(k−e_c)` plus exact current two-reroll chance transitions provides per-action U(s,a). The pointwise minimum over alpha choices and previous proven V28 bounds is still admissible. The quota optimization is **not** claimed to solve original terminal bonuses.

## Verification
- 5 independently computed **global exact Bellman reference positions** (10–14 turns), **92/92 legal action** new upper intervals ABOVE exact Q*, smallest observed slack **2.60983 BP**.
- An independent JavaScript finite-quota Bellman implementation on 4 smaller stochastic problems (1–3 active categories, quotas 1–2) agrees with new C++20 exact abstract Bellman and every current category Q to <2e−15 BP.
- The first C++ prototype inadvertently mapped all holds of one cardinality to one histogram; detected by the independent one-category Choice check, then fixed, and the final version subsequently passed cross-checks; erroneous prototype outputs are not used.
- Standalone ZIP integrity verified and `bash Oracle_31/run_checks.sh` **passed following fresh extraction**, including recompile, four abstract-model tests, 92 exact-Q checks, 252 opening benchmark, 36 previously completed observed cases aggregation. `RUN_HEAVY=1` can rerun all 36 from fixed seeds.
- Ordinary binary64 is used without V27 directed rounding, hence proof of admissibility is in exact real arithmetic, NOT a formal machine-verifiable interval certificate. No production integration.

## Crucial negative result / next necessary leap
**No top move on an ordinary 20–28-turn position is yet globally optimal certified.** The average opening regret upper still 13.46 BP, so still far too loose to prune actions. To close that gap, keep exact category-quota DP but track the *actual threshold progress / nonlinear Big Point bonus* for a selected 1–3 categories, while upper-majorizing the others; expand exact-coupled reward-state dimensions only when their impact on root U is material. Independent numeric certification and a genuine nontrivial observed early root top proof remain mandatory before any release.
