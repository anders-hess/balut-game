# Oracle v10 — proof-first research branch

**Status:** experimental; no game integration or production code changes.

The binding mathematical target and decisions are recorded in [docs/ORACLE_NORTH_STAR.md](../../docs/ORACLE_NORTH_STAR.md). The next steps and acceptance criteria are tracked in [Issue #1](https://github.com/anders-hess/balut-game/issues/1).

A standalone v10 prototype, independent exact reference, verified bounds and regression tests have been delivered as a ZIP attachment in the Balut ChatGPT project conversation. **The prototype implementation has not yet been merged into this branch**; do not interpret the branch as a deployable Oracle.

Before a future merge, bring over the prototype, integrate with the current code, run the tests in a reproducible Node environment, validate score rules and measure performance on mobile. No change to the live game should occur until explicitly accepted.
